# FR-05 공정 통합: 검사 카메라 빈 이미지로 정상 키트가 불량이 되고, 푸셔가 물건 든 박스를 못 민다

> 작성일: 2026-11-03 · 브랜치: `feature/pw-conveyor-dashboard-polish`
> 범위: 키팅 → 컨베이어 → 검사 → 정상은 팩킹·뚜껑·끝, 불량은 푸셔·불량 박스로 이어 붙이고 "정상 2 + 불량 1" 전체 공정 시험을 만들 때 만난 문제
> 결과: **헤드리스에서** `FullProcessTests`(정상 2·불량 1)와 `RejectPathTests`가 통과했다. **에디터에서 직접 확인한 것은 없다.**
> 표시: **확정**(로그·궤적·시험으로 확인) · **추정**(정황) · **미검증**

## 1. 정상 키트 3개가 모두 불량 (확정)

증상: 키트 1·2·3번 모두 `InspectionResult (불량)`. 경고에는 `INSPECTION_FALLBACK`이 없었다(= CNN이 판정을 "해냈다").
확인: 시험이 저장한 `InspectionCaptures/.../full.png`를 열어 보니 **회색 한 색 이미지**였다. `-nographics`에서는 카메라가 그리지 못하는데 `TryCapture`가 빈 텍스처를 그대로 돌려줬고, CNN은 그것을 전부 빈 슬롯으로 분류했다.
고침: `InspectionCameraRig.CanRender`(`SystemInfo.graphicsDeviceType != Null`)가 false이면 촬영을 실패로 돌린다 → 기존 설계대로 `INSPECTION_FALLBACK` 경고 후 슬롯 센서 규칙 판정. 그래픽이 있는 실행은 그대로다.
교훈: 판정 대체 경로("판정할 수 없으면 규칙 판정")는 입력이 **없을 때**만 타고, **쓸모없는 입력**(빈 이미지)에는 안 탄다. 배치 시험의 판정 방법은 로그의 `JudgeMethod`(Rule/Cnn)로 확인한다. **CNN 판정은 에디터에서 확인 전.**

## 2. 푸셔가 물건 든 박스를 못 민다 (추정이 강함)

증상: 불량 키트 3번에서 `PUSHER_KIT_OUTSIDE`. 궤적(`PushedBoxTrace`): 푸셔 헤드는 x 3.95→5.00→3.95로 움직였는데 박스는 (4.51, 0.90, 4.00)에 **그대로**. 빈 박스(`RejectPathTests`)는 속도 1.0m/s로 밀려 약 1초에 불량 박스에 들어갔다.
숨은 문제: 푸셔는 5초 안에 박스가 안 들어오면 "밖으로 떨어졌다"며 `KitRejected`를 대신 보내므로, 시험이 이 경고를 안 보면 **통과처럼 보인다**(실제로 한 번 거짓 통과). 누적 수(`Total`)에도 포함되므로 `Loaded`와 경고로 확인해야 한다.
원인(추정): 박스 안 물건은 `Graspable.Freeze()`로 **키네마틱 Rigidbody 자식**이다. 키네마틱은 물리 스텝 안에서 움직이지 않아, 푸셔가 박스에 동적 Rigidbody를 달고 밀면 박스가 안의 물건 접촉에 막힌다.
고침: 박스를 컨베이어에서 풀 때(`KitBoxConveyorRelease.ReleaseToPhysics`) 안 물건 충돌체의 `excludeLayers`를 전부로 해 접촉에서 뺀다(물건은 박스 자식으로 따라가기만 한다). `Graspable`이 `Rigidbody`를 필수로 요구해 Rigidbody를 지울 수는 없다. 고친 뒤 헤드리스 시험 통과(`[RejectBin] 들어왔다 적재 1/5`).
시험: `FullProcessTests`가 `PUSHER_KIT_OUTSIDE` 경고가 없을 것, `RejectBin.Loaded == 1`을 확인한다.

## 3. 검사 구간과 팩킹 정지의 끝 칸 충돌, 연결 접점 누락 (확정)

- `InspectionConveyorLine`(팀원)은 06번 칸에서 박스를 3초 멈췄다가 지운다. 06이 팩킹 정지 자리라 뚜껑 덮기·하역까지 못 간다 → `_handleEnd` 스위치, `ConveyorHandoffSetup`이 씬 인스턴스에서 끈다(프리팹 원본은 그대로).
- 검사 구간은 `Parcel`의 `KitBoxParcel`로 키트를 찾고, 푸셔는 박스의 `IBoxConveyorRelease`를 찾는다. 내 받침에는 둘 다 없었다 → 받침에 `KitBoxParcel`, 박스에 `KitBoxConveyorRelease` 중계를 붙인다.
- `ConveyorHandoffTests`는 빈 박스를 보내므로 검사 구간을 꺼서 컨베이어만 본다(검사·푸셔 포함 흐름은 `FullProcessTests`).
